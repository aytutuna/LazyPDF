# Turkish glossary

The same word is used everywhere in the app. Buttons are bare imperatives (Kaydet, Aç). Instructions and hints use the polite siz-form (Parolayı yazın). Messages say what happened and what to do. Confirmations use the passive -sın mı? form (Değişiklikler kaydedilsin mi?). Titles and buttons are in sentence case. Nouns stay singular after numbers (3 sayfa). A placeholder never takes a suffix.

Cancel is İptal on Windows. Words shared with Lazy Scan and Lazy Print keep their spelling there.

## One word for one thing

English first, because the Turkish follows the English. When two words name one thing in the app, the one in the first column wins and the other is not used for it.

| Use | Not | Turkish | Where |
|---|---|---|---|
| file | document | Dosya | A PDF the user has open or saved. "Document" is left to the accessibility checks, which quote the PDF terms. |
| picture | image | Resim | Everything a person sees. "Image" stays in PDF/A and structure messages that quote a key or a PDF term. |
| search | find | Ara | Text in the file: the search bar, the Search panel, the results. "Find" is kept for Edit text (Find with Replace) and for form fields and blanks. |
| make smaller | compress | Küçült | The Make smaller tool and its Home tile. "Compact" is Save compact, which drops the undo history (Sıkıştırılmış kaydet). |
| delete | remove | Sil | Content the user made or a whole page, field or saved set. |
| remove | delete | Kaldır | Taking something off: a list entry, a link, a stamp, protection, hidden data, a letter the font lacks. Never Çıkar. |
| clear | remove | Temizle | Emptying a list, a result or a text box. |
| erase | delete | Sil | The Eraser and Erase in Comment. |
| organize pages | edit pages | Sayfaları yönet | The Pages tool. Düzenle is Edit and nothing else. |
| edit | organize | Düzenle | Changing text, pictures, fields. |
| Review | inspect | Gözden geçir | The group of Comment, Measure and Compare files. Not İncele, which is too close to Denetle. |
| Optimize | compress | İyileştir | The group of Make smaller and Make searchable only; the tool stays Make smaller. |
| Check | inspect | Denetle | The group of Properties, Accessibility and PDF/A, and the Check button in their panels. |
| Security | protection | Güvenlik | The group of Protect, Redact and Clean for sharing. |
| properties | metadata | Özellikler | What the Properties tool shows. "Metadata" (Üst veri) is for the PDF/A and XMP messages. |
| bookmark | outline | Yer imi | Navigation inside the file. "Outline" stays in the PDF/A checks (Anahat). |
| mark | annotation | İşaret | A mark on a page from the Comment tool. "Annotation" (Ek açıklama) is the PDF term in the checks. A redaction mark is İşaret too. |
| note | comment | Not | The sticky note. A comment (Yorum) is a note or mark with replies. |
| password | PIN, key | Parola | Never Şifre, except in the verb şifrelemek for encryption. |
| make searchable | OCR | Aranabilir yap | The tool. OCR is named only for the language packs Windows needs. |

## Words that look alike

- Create (Oluştur) starts a new PDF. Make (Yap) derives one from what is open: Make smaller, Make searchable.
- Close (Kapat) a tab or a panel. Cancel (İptal) stops a job or a question. Don't save (Kaydetme) leaves a file as it is on disk.
- Export (Dışa aktar) is a different format. Save as (Farklı kaydet) is a PDF under another name.
- Batch (Toplu işlem) is the tool, a set is its saved list of steps (Küme).
