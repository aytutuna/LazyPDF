## English

**Name:** Lazy PDF

**Short description:** Read, fill, sign and edit PDF files on your PC. Free, offline, no account.

**Description:**

Lazy PDF opens PDF files and lets you change them. It is free, it works without an internet connection, and it has no account, no ads and no analytics.

Pick a job on the Home tab, or open a file and choose a tool from the strip under the tabs. You can highlight and leave notes, fill in forms, sign with a drawn signature or a certificate, rearrange pages, join and split files, change the words and pictures already on a page, add stamps, watermarks and page numbers, set a password, remove text and pictures for good, take hidden data out before a file goes to someone else, make a file smaller, save it as Word, Excel, PowerPoint, HTML, text or pictures, make scanned pages searchable, compare two files, and check a file for screen readers and PDF/A.

Every change is a step you can undo. While you work, an unsaved copy is kept on your PC, and the app offers it back if it closes by accident.

Lazy PDF is free, and its source is public to read. It is a sister app of Lazy Scan and Lazy Print: when Lazy Print is installed, Print hands the file to it, and when Lazy Scan is installed, a Scan tile appears on the Home tab.

Lazy PDF is new. If a file does not open or change as it should, write to support@alazy.app.

**Features:**

- Read PDF files with search, bookmarks, thumbnails, layers and attachments.
- Highlight, draw, add notes and measure distances and areas on a page.
- Fill in forms, and add or change form fields.
- Sign with a drawn signature or a certificate, and see in plain words who signed a file and whether it changed.
- Change the words and pictures already on a page, and add stamps, watermarks and page numbers.
- Rotate, move, delete, crop, extract, join and split pages.
- Protect a file with a password, or remove text and pictures from it for good.
- Take hidden data out of a file before you share it, or make the file smaller.
- Save as Word, Excel, PowerPoint, HTML, text or pictures, or make a PDF from pictures and text.
- Make scanned pages searchable with the text recognition built into Windows.
- Compare two files, and check a file for screen readers and PDF/A.
- Undo every change one step at a time, with an unsaved copy kept in case of a crash.

## Age rating

The IARC questionnaire in Partner Center, with what backs each answer. The rating this should give is 3+ (PEGI 3, ESRB Everyone); the questionnaire result is the Store's, not ours.

| Question | Answer | What backs it |
|---|---|---|
| Violence, fear, sexual content, bad language, drugs, gambling | No | The app shows the user's own files and nothing else; it has no content of its own besides its tool windows. |
| Users can talk to or share with each other | No | There is no account, chat, feed or sharing feature in the code. |
| Shares the user's location | No | No location API is called. |
| Shares personal information with others | No | The only network code is `Services/HttpSignatureTransport.cs`: a time stamp request or a validation data request, made only when the user signs with a certificate and asks for it. |
| Purchases, ads | No | None in the code or the manifest. |
| Unrestricted web access | No | The app has no browser. A link in a file shows its address and asks; only http, https and mailto are opened, by the user's own browser or mail program. |
| Collects or sends diagnostics | No | No analytics, crash reporting or update check in the code. |

## Privacy answers

- **Collects personal data:** No. Nothing is sent to the developer or to a server run for the app. `site/privacy.html` says so and lists the network requests, and the code agrees: `Services/HttpSignatureTransport.cs` is the only user of `HttpClient`.
- **Network use:** Only for time stamps and validation data when signing with a certificate, to the server addresses the user or the certificate names.
- **Data kept on the PC:** settings, the list of recent files, recovery copies of documents with unsaved changes and thumbnails, which in the Store build Windows keeps in the package's own store and removes when the app is uninstalled. The copies made for printing and for opening attachments go to the temp folder, outside the package, and uninstalling leaves any still there. `site/privacy.html` says so.
- **Account needed:** No.
- **Uses encryption:** Yes, for the PDF files it opens, writes, signs and protects (AES, RC4, RSA, SHA-2) through .NET and the Windows libraries. Partner Center asks about this in the export compliance part of the submission.

## Restricted capability

The package declares `runFullTrust` and nothing else. Partner Center asks for a reason:

> Lazy PDF is a desktop app built with .NET and WPF. It reads and saves the PDF files the user picks anywhere on the PC, starts the user's browser and mail program for links, hands a file to Lazy Print through a named pipe or a lazyprint: address, and runs the Windows PDF and text recognition components. It does not need to be sandboxed to do this, and it has no other capability.

## What only the owner can do in Partner Center

In this order.

1. Join the Windows developer program in Partner Center with the Aytu account (one-time registration fee; check what it is for an individual).
2. Create the app and reserve the name "Lazy PDF". If the name is taken, pick another and change `DisplayName` in `Package.appxmanifest` and the manifest's `Description` line to match.
3. Open Product management, Product identity. Copy three values into the repository's Actions variables: Package/Identity/Name as `STORE_IDENTITY_NAME`, Package/Identity/Publisher (the `CN=...` text) as `STORE_PUBLISHER`, and Package/Properties/PublisherDisplayName as `STORE_PUBLISHER_DISPLAY_NAME`.
4. Run the Release workflow from the Actions tab and download the `lazypdf-store` artifact, a file named `LazyPDF_1.0.0.msixupload`.
5. Optional but wise: install the package on a clean Windows 10 PC and a Windows 11 PC with a test signature and run the Windows App Certification Kit. Nobody has done this yet.
6. Start the submission. Pricing and availability: Free, all markets you want, visible in the Store.
7. Properties: category Productivity, the privacy policy URL and support contact above, and the system requirements (Windows 10 version 2004 or later; x64 and arm64).
8. Age ratings: answer the questionnaire as in the table above.
9. Packages: upload the `.msixupload`. Give the `runFullTrust` reason above when asked.
10. Store listings: add English and Turkish. Paste the texts, upload the screenshots with their captions and the three logos from `Listing/`.
11. Notes for certification: "No account is needed. Open any PDF with the Open tile."
12. Submit. When it is certified, add the Store link to `site/index.html` where the comment in the hero marks the place, and drop the "Not released yet" line.
