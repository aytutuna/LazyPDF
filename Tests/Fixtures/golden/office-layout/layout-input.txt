# section: a new section; page <w> <h> <top> <right> <bottom> <left> [headerDistance footerDistance] sets its geometry.
# band header|footer|body: where the paragraphs that follow go (body is the default).
# p <key=value ...>: a paragraph. Keys: align (left center right justify), left, right, first, before, after, line, rule (multiple exact atleast), keep, break, nowidow.
# r <key=value ...> | <text>: a run of the last paragraph. Keys: font (_ for a space), size, b, i, u, s, color (RRGGBB), hl (RRGGBB), shift, field (page pages).
# pagebreak: a hard page break. skip <kind> <count>: a feature the reader left out.
