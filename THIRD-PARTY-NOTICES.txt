sRGB colour profile (Standards/PdfASrgb.cs)
    "sRGB-v2-magic.icc" from Compact-ICC-Profiles by Clinton Ingram,
    https://github.com/saucecontrol/Compact-ICC-Profiles, released to the
    public domain under CC0 1.0. It is the output intent of PDF/A files the
    app writes. The 736 bytes in the source were checked against the SHA-256
    recorded there, af4efe28f6d311799865f325ba39184a2e978b113ca74124d60af7de22b105f4.

Encoding tables (Fonts/Tables/EncodingData.cs, Fonts/Programs/StandardNames.cs)
    StandardEncoding, WinAnsi, MacRoman, MacExpert, PDFDocEncoding, Symbol and
    ZapfDingbats from ISO 32000-1 Annex D; the 391 CFF standard strings from
    Adobe Technical Note 5176; the 258 Macintosh glyph names of the TrueType
    'post' table from Apple's TrueType reference manual. These are lists of
    names fixed by the specifications.

Written for this project and needing no notice: the invisible-text font used
for OCR (built from code, not a font file), the PDF/A XMP packet, and the code
taken over from Lazy Scan and Lazy Print, which have the same author.
